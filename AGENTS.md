## Unslop Design Standard: Premium SaaS & Web UI Craft

Follow the Unslop UI framework across all components, pages, and styling:

1. **Zero AI Slop:** No purple-indigo gradients (`from-purple-600 to-indigo-600`), no floating neon blur blobs, no plain Inter/Roboto headers, no 3-card generic formulas, no emoji-as-icons, and no springy bouncy hover transforms.
2. **High-Density Craft:** Hairline borders (`border-border/80`), semantic surface layers (`bg-background`, `bg-card`, `bg-muted/40`), tight heading typography (`tracking-tight leading-[1.15]`), and monospace tabular figures for numbers/prices (`tabular-nums font-mono`).
3. **Real Utility First:** Pair visual aesthetics with functional tools (live quote calculators, interactive bag drawer with threshold progress, filterable catalogs, instant feedback).
